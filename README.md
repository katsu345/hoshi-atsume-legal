# 星あつめ 法務・サポートサイト

集中タイマー「星あつめ」のサポート、利用規約、プライバシーポリシー、
特定商取引法に基づく表記を公開するサイトです。

GitHub Pagesで `https://katsu345.github.io/hoshi-atsume-legal/` に公開します。
公開環境の `SUPPORT_EMAIL` はGitHub ActionsのRepository secretで管理し、
個人情報をリポジトリへ保存しません。

## ページ

- `/hoshi-atsume-legal/` — サポートトップ
- `/hoshi-atsume-legal/terms-of-service/` — 利用規約
- `/hoshi-atsume-legal/privacy-policy/` — プライバシーポリシー
- `/hoshi-atsume-legal/tokushoho/` — 特定商取引法に基づく表記

`main`へのpushでGitHub Actionsが静的HTMLを生成・公開します。
